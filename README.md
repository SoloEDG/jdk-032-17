# 骨牌造境

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8032>。端口可通过 `DOMINO_LAB_PORT` 修改。

## 刚体倒下与接触区间模型

倒下不再是瞬时事件。每张骨牌按绕底边铰接的匀质杆建模，用 RK4 积分倾倒角
`θ¨ = (3g/2L)·sinθ − d·θ˙`，从站立、旋转、接触到着地的姿态与经过时间都写进
同一条 `FallTrajectory`。

- **接触时间范围**：固定帧上观察间隙函数 `gap` 的符号变化，由相邻的未接触时刻
  `tLower` 与首次接触时刻 `tUpper` 夹出 `[tLower, tUpper]`，再从缓存的帧起点状态
  做局部二分求 `tEstimate`。细化只重积分当前骨牌，不改动全局帧时钟，因此远处已
  确认的接触时刻不会整体漂移。
- **先后判定**：两个接触区间不重叠才能确定先后；区间重叠则在事件表与画布上标记
  为「未定」（分岔）。
- **坡道回弹**：碰到坡道唇边后朝向按恢复系数偏转、底边侧向滑移，骨牌在偏转后的
  平面内继续向前旋转，回弹可继续击中近邻并驱动下游。
- **慢放**：回放按 `FallTrajectory.samples` 插值渲染真实倾倒角，事件表、画布姿态与
  中断点全部来自同一次模拟。

## 无头验证

```sh
npm run verify
```

两个内置场景各自只运行一次模拟：

- 验证 A：侧倒碰坡道边 → 侧向回弹 → 击中近邻 → 触达终点触发器；
- 验证 B：两个首次接触区间重叠 → 顺序标记为未定。

另外还校验缩步不整体漂移，以及慢放姿态、事件表、中断点来自同一次模拟。
应用内「验证 A 回弹 / 验证 B 分岔」按钮载入的就是这两份场景定义。
